# vector_v1_vslam
This is a work-in-progress addition the astablished vector_v1 project developed by Multi-Robot Systems (MRS) Lab, German University in Cairo (GUC). In this partion we have the addition of the setup and data streaming of the Raspberry Pi camera, Built-in IMU and wheel encodders.

# Setup Guide
please refer to the following repo where you can find how to set up the essantials of the project:
https://github.com/Hazem-M-Abdelaziz/vector_v1/tree/main
once you have followed the previous repo and have everything set up you can now use the additions in this repo.
